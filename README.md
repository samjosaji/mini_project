# VendoraApp

## 📌 Overview
VendoraApp is a multi-role mobile marketplace application built using React Native (Expo) and Supabase. It connects customers, vendors, and admins in a unified platform.

## 🚀 Features
- Customer, Vendor, Admin roles
- Real-time product and vendor management
- Location-based vendor discovery
- Notifications system
- Favorites and reviews
- Background location tracking

## 🛠 Tech Stack
- React Native (Expo)
- Supabase (Auth, Database, Storage)
- PostgreSQL
- Leaflet Maps
- Expo Location API

## 🧩 Architecture
- Frontend: React Native
- Backend: Supabase
- Role-based navigation
- Service-based modules

## 🔮 Future Scope
- Payment integration
- Push notifications
- AI recommendations
- Scalability improvements
